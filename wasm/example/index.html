SILO WASM Example

Minimal example showing how to write files into the Emscripten filesystem, preprocess them with SILO (from NDJSON, from a BAM file, or from a FASTA file), save the processed state, load it again, and run SaneQL.

Serve this page over HTTP with Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp, because the current SILO WASM build uses pthreads.

1. Preprocess input files

Upload the files referenced by your preprocessing config, for example preprocessing_config.yaml, database_config.yaml, reference_genomes.json, and an NDJSON input file.

2. Preprocess a BAM file

Upload a .bam file together with the same config files (preprocessing_config.yaml, database_config.yaml, reference_genomes.json). Point the config's input file at the uploaded .bam: each read is projected onto reference coordinates and ingested through the normal append pipeline. The table columns are drawn from the BAM fields (qname, flag, rname, pos, mapq, cigar, ...) plus one nucleotide-sequence column.

3. Preprocess a FASTA file

Upload a .fasta file together with the same config files. Each record's > identifier becomes the primary key and its sequence is ingested into the table's sequence column. Sequences are taken to be already aligned to the reference (same coordinates, gaps as -). The table schema should declare only the primary-key column and a single sequence column.

4. Load processed state and query

The JSON file is only this example's archive format; SILO itself saves and loads a directory of processed state files.
